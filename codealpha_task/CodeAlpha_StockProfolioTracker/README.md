# 📈 CodeAlpha Stock Portfolio Tracker

## 📌 Description
A Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship.

This application allows users to manage a virtual stock portfolio by buying and selling stocks, viewing holdings, checking stock prices, and saving portfolio data using JSON.

## ✨ Features
- Buy stocks
- Sell stocks
- View portfolio
- Search stock prices
- Calculate total portfolio value
- Save and load portfolio automatically using JSON

## 🛠️ Technologies Used
- Python 3
- JSON
- Object-Oriented Programming (OOP)

## ▶️ How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python stock_tracker.py
```
