# Hangman Game

## Description
This is a simple Hangman Game developed in Python as part of the CodeAlpha Internship. The game randomly selects a word, and the player has to guess it one letter at a time within a limited number of attempts.

## Features
- Random word selection
- Letter-by-letter guessing
- Limited attempts
- Win and lose messages
- Easy-to-use console interface

## Technologies Used
- Python 3
- Random module (built-in)

## How to Run
1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:
   ```bash
   python hangman.py
   ```
